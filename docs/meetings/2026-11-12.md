MDP 설정

===메뉴, 재료===
메뉴 2, 재료 3
메뉴 0: 주문 없음
메뉴 1: 치즈 피자
메뉴 2: 페퍼로니 피자
재료 0: 피자 기본 도우
재료 1: 치즈
재료2: 페퍼로니

===재료 순서===
치즈피자: 도우->치즈->서빙
페퍼로니 피자: 도우->치즈->페퍼로니->서빙

===state===
S=(d, c, p, m1, t1, m2, t2)

변수		의미			값
d		도우 유무		0, 1
c		치즈 유무		0, 1
p		페퍼로니 유무		0, 1
m1		주문 1의 메뉴		0, 1, 2
t1		주문 1의 남은 시간	0~8
m2		주문 2의 메뉴		0, 1, 2
t2		주문 2의 남은 시간	0~8


===action===
0: 대기 (Idle)
1: 도우 올리기 (0)
2: 치즈 뿌리기 (1)
3: 페퍼로니 올리기 (2)
4: 오븐에 굽고 서빙하기 (현재 조리대의 재료 조합이 대기 주문 중 하나와 일치하는지 확인)

===reward===
상황   Reward
정확한 피자 서빙   +20
잘못된 피자 서빙   -15
주문 시간 초과   -10
잘못된 재료 순서   -2
동일한 재료 중복 추가   -2
Idle   추가 감점 없음
모든 행동   -0.1
